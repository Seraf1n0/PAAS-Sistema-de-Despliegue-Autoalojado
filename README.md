# PAAS-Sistema-de-Despliegue-Autoalojado
Una plataforma autoalojada (tipo Dokploy/Easypanel simplificada) que, a partir de un repositorio de GitHub, construya la aplicación con Docker, la despliegue en un VPS detrás de un proxy inverso con HTTPS automático y permita operarla (logs, variables, rollback, métricas).
